# Нераспознанные даты ошибочно закрывали тур

2026-11-02, локальное исправление после согласованного плана. Не считать
доказанной причиной старых отказов Белостока: см. bialystok-old-denials.md.

Root cause: _extract_tour_section всегда превращал пустой список доступных
дат в «Свободных дат нет», даже если дата вообще не распознана. Подпись
Когда была чувствительна к регистру, одиночная дата не поддерживалась,
валидировалось только начало диапазона.

Fix: общий DOCX/Drive parser принимает подписи Когда/Даты/Дата выезда/
Даты выезда, пробелы/тире, одиночную дату с годом; валидирует начало/конец/
порядок. Неизвестные/неполные/незавершённые записи дают «Даты требуют
уточнения». Проверенные будущие сохраняются рядом с пометкой неполноты.
Старое закрытие допустимо лишь при полностью проверенных прошедших/закрытых
датах. Граница описания/другого поля закрывает блок дат; одиночные даты вне
блока не становятся заездами. Прежние самостоятельные диапазоны до описания
сохранены для совместимости. Год одиночной даты не угадывается.

Prompt позволяет прислать программу при неизвестных датах без обязательной
эскалации; недостающие даты уточняются только по конкретному вопросу клиента.
Existing metadata available=null/true/false уже поддерживает эти состояния;
SQLite/JSON/transport не меняются. Это инструкция модели, не доказанная
гарантия её будущих ответов; ручных платных проверок не было.
