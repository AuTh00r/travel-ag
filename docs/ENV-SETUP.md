# Настройки окружения

Источники истины: [Settings](../src/config.py) и [публичный шаблон](../.env.example). Код читает `.env` из рабочего каталога. Пути задавай для выбранной системы.

## Новая среда и миграция

Для новой тестовой среды создай `.env` из шаблона, если файла ещё нет. При переносе сохрани рабочую конфигурацию защищённо и адаптируй пути. `.env_old` — историческая резервная копия, автоматически не подключается.

Не публиковать `.env*`, токены, `credentials/` и рабочие клиентские данные. Исключение — подготовленный `.env.example` без секретов. Не выводить реальные настройки в отчёты.

## Группы настроек

| Группа | Что проверить |
| --- | --- |
| DeepSeek | `DEEPSEEK_API_KEY`, `DEEPSEEK_MODEL`, `DEEPSEEK_VISION_MODEL`; live-вызовы разрешаются отдельно |
| Instagram | `INSTAGRAM_APP_SECRET`, `INSTAGRAM_ACCESS_TOKEN`, `INSTAGRAM_VERIFY_TOKEN`, ID аккаунта и приложения; production требует проверки подписи |
| Telegram | `TELEGRAM_BOT_TOKEN`, `TELEGRAM_MANAGER_CHAT_ID`, дополнительные разрешённые чаты |
| Каталог | DOCX в `tours/`, `TOUR_SYNC_*`, snapshot; старый пример Sheets-каталога не соответствует текущему коду |
| Google Drive | `GOOGLE_DRIVE_CREDENTIALS_FILE`, `TOUR_SYNC_FOLDER_ID` и остальные поля Settings; сохранить разрешённый доступ |
| FAQ | `CHROMA_DB_DIR`; без согласованных TXT поиск отключён, старый индекс не является источником истины |
| Медиа | Независимые `STORY_MEDIA_ENABLED`, `IMAGE_MEDIA_ENABLED`, `SHARED_MEDIA_ENABLED`, `ADS_MEDIA_ENABLED` |
| Голос | `VOICE_MEDIA_ENABLED`, отдельный `VOICE_PYTHON_EXECUTABLE`, `VOICE_MODEL_DIR`; отдельное окружение `requirements-gigaam.txt` |
| Recovery/reconcile | `INBOUND_RECOVERY_*`, `INSTAGRAM_RECONCILE_*`; defaults и реальные серверные флаги — разные состояния |
| Модельный транспорт | `DEEPSEEK_TOOL_SCOPE`, `DEEPSEEK_TOOL_CLIENT_IDS`; не расширять охват при переносе |
| Администрирование | `ADMIN_API_TOKEN`; reset и другие записи не относятся к нейтральной диагностике |

Точный перечень, типы и defaults смотри в Settings. Не все поля обязательны для каждого сценария. Рабочие production-значения нельзя вывести из шаблона.

## Данные и пути

- Сохранять `data/sessions.db` вместе с WAL/SHM при остановленном локальном процессе; не коммитить клиентскую БД.
- Сохранять `credentials/` и файлы, указанные в настройках, без публикации.
- Внешний каталог моделей копируется отдельно.
- На Mac `.venv/bin/python` заменяет Windows `.venv\Scripts\python.exe`; для голоса используется интерпретатор отдельного окружения.
- `C:\...` и `D:\...` не превращаются в Mac-пути автоматически.

Сначала `pip check`, offline pytest и Ruff: [SETUP](SETUP.md). Перед запуском проверить тестовые подключения и фоновые флаги: старт с рабочими ключами может выполнять внешние операции.

Создание аккаунтов, выпуск ключей и выдача разрешений — отдельные процедуры сервисов. Старые даты, цены и учебные туры не являются рабочими бизнес-данными.
