# MCP и подключения агента

MCP относится к окружению Codex. Бот использует собственные Python-интеграции и `.env`; MCP не заменяет настройку бота и не переносит его базу.

## Перенос

Пути, зависимости и проверки — в [гайде](CODEX-WINDOWS-TO-MAC.md#10-mcp-и-плагины). На проверенном Windows-профиле есть `node_repl`, `context7`, `gh_grep`, `playwright`, `openaiDeveloperDocs`: это снимок профиля, не обязательные зависимости бота.

1. Сохранить `config.toml` и исходники собственных плагинов.
2. Использовать Mac-компоненты новой установки; не запускать Windows `node_repl.exe` и не применять старые runtime-пути.
3. Восстановить нужные плагины и авторизацию через интерфейс.
4. При установленном CLI проверить `codex mcp list`, затем получить ответ на запрос чтения к каждому нужному инструменту.

## Google Drive

Для работы агента с Google-документами использовать доступное авторизованное подключение. Не выпускать новые ключи и не ставить серверы только из-за смены ноутбука, если существующего подключения достаточно.

Настройки бота описаны в [ENV-SETUP](ENV-SETUP.md); синхронизация каталога из Drive реализована в `src/services/tour_sync.py`. MCP агента и runtime бота — разные подключения.

Прежние непроверенные рецепты ZCode и установки пакетов с угадываемыми именами убраны из активного руководства. Сторонний сервер устанавливать по его проверенной документации под конкретную задачу.
