# Sundita Travel Agent Bot

Python/FastAPI-бот турагентства для Instagram Direct: каталог туров, обработка сообщений и медиа, SQLite-очереди, уведомления менеджерам в Telegram. Production работает на Windows с Cloudflare Tunnel; перенос на Mac относится к среде разработки.

## Локальная папка, GitHub и сервер

По журналу последней проверенной выкладки: **4 ноября 2026, 01:09 Europe/Minsk**, quiet-window установлен пакетом двух серверных исходников; проверка после рестарта — 01:16. Это была прямая выкладка файлов, без синхронизации всей работы с GitHub: [журнал](runtime/inbound-quiet-window.md).

Исправление SDK/таймаутов **N42 не вошло в этот деплой**: [статус](runtime/provider-response-deadline.md). Текущий снимок разработки включает N42, поэтому отличается от production. Публикация снимка в GitHub сохраняет код для клонирования, но не устанавливает его на сервер. Это датированный журнал, а не свежая проверка работающего сервера.

После клонирования сверить ветку и commit, установить зависимости и отдельно восстановить приватные настройки/данные. Перед будущими коммитами проверять новые файлы, удаления и секреты. Коммит, push и deployment — самостоятельные действия.

## Что сохранять

- `.env`, `credentials/` и резервные настройки — приватные файлы.
- `data/sessions.db` с соседними WAL/SHM — рабочие данные и очереди.
- `tours/` и `data/tours_snapshot.json`, если существует, — каталог и snapshot.
- [FAQ](data/faq/README.md) намеренно не содержит неподтверждённых TXT. Не восстанавливать отменённые стартовые FAQ из старого Git-снимка.
- `.kiro/`, `runtime/`, `.agents/` и тесты — контекст разработки. Старый экспорт `context.md` не является текущей спецификацией.
- Временные `.tmp-*`, `.tmp_docx_qa` и кеши архивируются отдельно; они не являются рабочими данными и не публикуются в Git.

## Ограничение Mac

`src/services/story_media.py` вызывает Windows PowerShell по жёсткому пути. Установка Python-зависимостей не делает story/video переносимым. GigaAM требует отдельного окружения и моделей. Подробности — в гайде переноса.
