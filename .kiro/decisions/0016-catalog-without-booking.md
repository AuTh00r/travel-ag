# 0016. Catalog Without Booking

## Status
accepted

## Context
Новые документы Drive исключались из каталога без URL бронирования. Владелец26октября подтвердил, что хочет видеть эти туры.

## Decision
Ссылка бронирования необязательна для включения тура; пустой booking_url сохраняет отсутствие данных. Описания доступны, оформление без ссылки направляется менеджеру. Подтверждённые ссылки наследуются как прежде.

## Consequences
Новые туры доступны без ручных алиасов. Запрещено придумывать URL; существующие пороги валидации сохраняются. Старое исключение без брони отменено актуальным запросом.
